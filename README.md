# X Keyword Blocker

[English](README.en.md)

一个轻量、无依赖的 Tampermonkey / Violentmonkey 用户脚本，用关键词和广告标记自动隐藏 X（Twitter）时间线中的帖子。支持 `x.com` 与 `twitter.com`。

## 功能

- 不区分大小写的关键词匹配，支持 Unicode 规范化，可选**整词匹配**（针对 ASCII 英文单词精确匹配单词边界，避免误伤复合词；CJK 自动维持子串匹配）
- 灵活的**过滤作用域**：支持“全站页面”或“仅首页时间线”（在个人主页、搜索结果与帖子详情页自动放行，避免误伤）
- 可选匹配作者显示名称和 `@username`
- 独立屏蔽“广告 / Promoted / Sponsored”等推广帖子，无需依赖关键词
- **多维度拦截统计**：持久保存累计拦截总数、**今日拦截**与**近 7 日拦截**计数，并可在页面上显示 `+N` 浮动提示（附带命中关键词）
- **快捷屏蔽**：帖子右上角悬浮图标一键屏蔽该作者（`@username`）或选中的文字，无需打开面板
- **关键词有效期（临时屏蔽）**：支持为单个关键词设置 24 小时、7 天、30 天或自定义截止日期，实时显示剩余时间徽标，到期自动清理并汇总通知
- **远程词库订阅与自动同步**：支持订阅公开 HTTPS 纯文本词表并配置更新间隔（12小时 / 24小时 / 3天 / 7天），启动与打开面板时自动同步（只增不删合并策略，同会话 10 分钟防抖）
- **完整迁移包与规则导入导出**：
  - 支持导出/导入本地 TXT 规则文件（单行文本）及远程 HTTPS 网址导入
  - 支持导出/恢复**完整 JSON 迁移包**（完整备份关键词、有效期、过滤配置、拦截统计与词库订阅）
- 支持暂停过滤、一键清空关键词、深浅色和移动端布局自适应
- 自动跟随浏览器语言，支持中文和 English 界面

## 安装

1. 安装 Tampermonkey、Violentmonkey 或其他兼容的用户脚本管理器。
2. 点击[一键安装链接](https://raw.githubusercontent.com/livingfree2023/x-keyword-blocker/main/x-keyword-blocker.js)（国内加速镜像：[jsDelivr 镜像](https://cdn.jsdelivr.net/gh/livingfree2023/x-keyword-blocker@main/x-keyword-blocker.js)）直接安装；或者新建用户脚本，粘贴 [`x-keyword-blocker.js`](x-keyword-blocker.js) 的完整内容并保存。
3. 打开或刷新 `x.com` / `twitter.com`。

通过链接安装的脚本将通过 `@updateURL` 自动检查并接收后续更新。已有关键词、统计和开关设置会在升级后保留。

## 使用

从用户脚本管理器菜单选择“管理屏蔽关键词”。快捷键为：

- Windows / Linux：`Alt + Shift + K`
- macOS：`Option + Shift + K`

如果快捷键被浏览器或输入法占用，请使用用户脚本菜单。

面板中的“语言”可选自动、中文或 English；切换后会立即重新打开面板。

### 配置设置

| 设置 | 默认值 | 说明 |
| --- | --- | --- |
| 过滤状态 | 开启 | 控制全部过滤功能的主开关 |
| 浮动拦截提示 | 开启 | 拦截后在屏幕左下角显示累计数和 `+N` 提示，2 秒后消失 |
| 匹配作者名称与 ID | 关闭 | 同时检查帖子发布者的显示名称和 `@username` |
| 屏蔽广告 | 开启 | 独立隐藏带有推广、广告等标记的帖子（不依赖关键词列表） |
| 整词匹配 | 关闭 | 仅对英文字母/数字关键词生效，严格匹配独立单词边界，避免如 `act` 误拦截 `reactor`；中文等无分词字符自动保持子串匹配 |
| 过滤作用域 | 全站页面 | 可选“全站页面”或“仅首页时间线”（仅在 `/` 与 `/home` 首页生效，个人主页、搜索页等放行） |
| 被拦帖子展示 | 直接移除 | 可选“直接移除”或“折叠占位条”（折叠后显示命中关键词，点击占位条可临时展开该帖） |

### 关键词有效期（临时屏蔽）

在关键词列表每一项右侧，可点击时钟按钮设置有效期：
- **永久有效**：默认无时间限制。
- **24 小时 / 7 天 / 30 天**：快速设置短期屏蔽。
- **自定义日期**：输入有效天数（如 `3`）或具体截止日期（`YYYY-MM-DD`）。
- 列表项会以徽标形式展示剩余时间（如“剩 3 天”）；脚本启动或打开管理面板时，会自动清理已到期的关键词并弹出汇总提示。

### 词库订阅与自动同步

在面板中的“词库订阅”模块，可添加公开的远程 HTTPS 词库链接：
- 设置同步周期（每 12 小时、24 小时、3 天、7 天）。
- 脚本启动或打开面板时，若距离上次同步已到期，将自动拉取最新词表并合并至当前规则库（采用“只增不删”合并策略）。
- 同一页面生命周期内具备 10 分钟防抖节流与网络防重入机制，亦可在面板中随时点击“立即同步”。

## 导入、导出与迁移备份

### 1. TXT 词表导入与导出

TXT 文件每行一个关键词：

```text
广告
crypto
airdrop
```

导入时可选择：
- **合并导入**：保留现有关键词并添加新词。
- **替换现有**：用导入内容覆盖当前列表。

限制：最多 2,000 个关键词；每个关键词最多 100 个字符；文件最大 512 KB；URL 必须为公开的 HTTPS 纯文本地址。支持 GitHub Raw、Cloudflare Pages 等地址。

URL 导入使用用户脚本管理器的跨域请求权限。脚本只请求你主动填写的地址，不携带登录 Cookie。

### 2. 完整迁移包（JSON 备份）

- **导出迁移包**：点击“导出迁移包”可下载生成 `x-keyword-blocker-backup-YYYY-MM-DD.json`，完整备份关键词列表、有效期配置、过滤设置、历史拦截统计以及所有词库订阅。
- **导入迁移包**：点击“导入迁移包”选择备份文件，会弹出预览面板展示词数变化与设置项差异，确认后即可一键无缝恢复。

## 说明

- 累计拦截数与今日统计保存在当前浏览器本地；刷新页面后再次命中同一帖子会继续累计。
- 所有关键词、配置、订阅与统计数据仅保存在浏览器用户脚本管理器的本地存储中，绝不上传任何第三方服务器。
- X 页面结构发生变化时，脚本选择器可能需要更新。
